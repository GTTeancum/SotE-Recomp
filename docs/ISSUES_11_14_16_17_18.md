## Implemented and tested in harnesses

- WASD menu navigation now follows the digital arrow-key path.
- Controller X is excluded from native menu confirmation. Raw X remains
  available to the binding editor.
- Focusing Controls keeps the Options list visible; Enter/A opens the binding
  editor. Left/Right still selects the native preset before entering.
- Modern flying sections expose WASD and Mouse 1. Mouse motion feeds their
  native analog input; Classic retains its PC defaults.
- Existing vehicle controller assignments retain their saved keys across
  Classic and Modern layouts. Keyboard assignments remain separate.
  The compatibility harness verifies all three vehicle binding groups.
- Mouse capture is requested only for focused gameplay, and released for
  menus, movies, focus loss, resizing and closing. Offscreen runs never
  confine the host cursor. Only the capture policy has been tested.
- Modern view selection and pitch survive temporary input disconnection.
- Swimming no longer disables Modern aiming. Normal on-foot actors use
  health to detect death: flag `0x400` is also set underwater while alive.
  The train actor retains its separate existing death check.
- Modern projectile convergence follows every valid native camera slot,
  including slots selected after death, rather than silently stopping
  outside the shoulder camera.

`menu_revamp_harness`, `modern_controls_harness` and `modern_aim_harness`
passed together. The menu harness exercises keyboard and mouse-button
reassignment, file persistence and reload. It also verifies that Enter/A
opens the editor explicitly. These tests did not reproduce failed rebinding.
The aiming harness checks all six camera slots with a tilted camera ray.
